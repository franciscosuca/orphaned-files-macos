# orphaned-files-macos

A small macOS utility for finding and safely cleaning up orphaned application data folders.

## Project Structure

- `cleanup-files.sh`: Main Bash script. Scans hidden folders in a user's home directory, detects likely orphaned app data, and offers recoverable or permanent deletion.
- `guide-kimik3.md`: Current usage and implementation guide for the cleanup script.
- `README.md`: Project overview and structure.
- `archive/`: Older, untested guide and script proposals.
  - `ntested-guide-gpt-luna5.6.md`
  - `nok-guide-gemini3.7.md`

This project has no package manager configuration or application source tree; it is a script-based macOS utility.
